Gorae Shorts Uploader

YouTubeUses YouTube API Services

Gorae Shorts Uploader is a private, single-user tool used by the owner of the YouTube channel 고래야미안하다 (@sorrytowhale1) to upload and schedule short videos that the owner produces to that same channel.

It uses the YouTube Data API (scope youtube.upload) only to upload videos and set their titles, descriptions, tags, privacy status and scheduled publish time. It is not offered to other users.
