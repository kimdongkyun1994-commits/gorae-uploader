Privacy Policy

YouTubeUses YouTube API Services

Last updated: 2026-11-12

Gorae Shorts Uploader ("the app") is used only by the owner of the YouTube channel @sorrytowhale1 to upload the owner's own videos to that channel.

Data accessed

The app requests only the https://www.googleapis.com/auth/youtube.upload scope. It uploads video files and sets video metadata (title, description, tags, privacy status, scheduled publish time). It does not read, collect, or store any other YouTube or Google user data.

Data storage

The only stored credential is the OAuth refresh token of the channel owner, kept encrypted in GitHub Actions Secrets. No personal data of any other person is collected, stored, sold, or shared.

YouTube API Services

This app uses YouTube API Services. By using this app, you agree to be bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube API Services Terms of Service. YouTube's Terms of Service: https://www.youtube.com/t/terms · Google Privacy Policy: https://policies.google.com/privacy

Data retention and deletion

The app stores no YouTube data. The only stored item, the encrypted OAuth refresh token, is deleted immediately when access is revoked or on request, and in any case the app does not retain it longer than needed to provide the upload function. You can request deletion via the channel's About page.

Revoking access

Access can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions.
